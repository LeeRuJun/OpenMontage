# Historical Commentary Craft — 历史故事结尾点评写作手艺

A Layer-2 creative skill. Use when writing the post-story commentary (独立点评) for the `historical-story` pipeline — or any narrated history piece that ends with an evaluative turn.

**Self-contained:** consume this skill INSTEAD of stacking writing frameworks. The script-director still owns event narration; this skill owns only the closing evaluation.

---

## What the masters actually do

| 评述人 | 核心方法 | 结尾套路 | 一句话风格 |
|---|---|---|---|
| **易中天（百家讲坛·品三国）** | "以故事说人物，以人物说历史，以历史说文化，以文化说人性" — 四级火箭，层层升维 | 落在**人性**上收：权谋讲完，最后讲的是人心 | 帅哥/跳槽这类现代词砸进正史，严肃里带损 |
| **王立群（百家讲坛·读史记）** | 细读文本（考据），以今释古 | 落在**命运 vs 选择**：一个人的结局，是他性格与时代的合谋 | 学者型说书人，严谨打底，通俗落地 |
| **罗振宇（罗辑思维/得到）** | 反常识轶事 → 拆掉旧认知 → 换个"高维"心智模型 | 落在**认知升级**："这个故事告诉我们一个思维模型" | 卖的不是历史，是"换个角度想问题" |
| **当年明月（明朝那些事儿）** | 小说笔法讲制度史，全书埋"气数/大势"伏线 | 全书收在徐霞客：**"成功只有一个——按照自己的方式，去度过人生"** — 150万字官场倾轧后，用一个小人物反杀整套成功学 | 网感 + 冷幽默，狠话 preceded by 铺垫 |

**共性拆解：** 每个人都做同一件事 — 讲了一路事实，最后**换一个坐标系**再讲一遍。易中天换到人性，王立群换到命运，罗振宇换到认知模型，当年明月换到人生定义。故事负责"发生"，点评负责"意味"。

**风险提醒：** 罗振宇式结尾已被舆论反噬（"讲个故事升个维"的嘲讽、卖焦虑的批评）。升维必须从已讲事实里长出来；悬浮的人生哲理（"历史总是惊人的相似"）等于自杀。

## The framework: 五尺度 + 三动作

### 五个尺度（选 1–2 个，由内向外）

```
个人 → 国家 → 时代 → 文化 → 历史走向
```

### 评价角度：三家六面（人/局/流）

所有评价角度归纳为三个家族。每个家族内部的词可互换，家族之间的关系才是选择问题：

```
人（微观）—— 个人 · 人性 · 命运
            谁的代价，谁的选择，人在极端处露出什么
局（中观）—— 政治 · 博弈 · 国家 · 制度
            谁在较劲，各方要什么付什么，合力如何出结果
流（宏观）—— 时代 · 文化 · 民族 · 历史走向
            浪往哪去，改变了什么传统，留下什么记忆
```

**六面详解：**

- **个人/人性**（那个人）：这件事把这个人变成了什么样？恐惧、体面、韧性——人性在极端处露出什么？
  - 例："乌台诗案没有成就苏东坡，只是逼出了苏东坡"——重建是他挣扎的成果，不是打击的赠品
- **政治**（那台机器）：制度的合力揭示了什么？权力如何处置异见？
  - 例："不杀废其权，不灭慑其群——可控性处置"；"每一环都没有人越轨"
- **博弈**（那张棋局）：局中各方——皇帝、御史、太后、旧党、朋友——各自想要什么、付了什么、谁赢了？
  - 例：神宗要的是威慑不是尸体；王安石出手救政敌，买回的是道义分；李定推到最狠处，输了身后名
- **时代**（那个年代）：那个时代为什么需要这场案子？当时正常、今天骇人的是什么？
  - 例：不是苏轼运气差，是新法推行期需要一个"文字能定罪"的先例
- **文化**（那种文明）：文字成为证据之后，写作者的传统失去了什么？
  - 例：自我审查从何时开始；士大夫还敢不敢以诗议政
- **历史走向**（那条长河）：涟漪荡到哪里去了？
  - 例：北宋党争的深化 / 文字狱传统 / 后世记住的苏轼与真实的苏轼

**发散位（第八面之后——锦上添花，不承重）：**

- **同类共振**：历史长河里的同构事件——乌台诗案之前有北魏崔浩国史之狱，之后有明清文字狱，近代更有回声。"这不是第一场，也不是最后一场"能把一期节目接进一条长线，观众自己会起鸡皮疙瘩。
- **反向对照**：同类情境的不同结局——如果苏轼生在清代文字狱顶峰，还出得来吗？没有出狱当天写诗的任性，还有东坡吗？对照让"这次为什么不同"显形。
- **古为今鉴**：故事映进观众自己的生活——写东西的人被截图、被断章取义，谁不熟悉？用一次即可，点到即收；说教两句就俗。
- **悖论留白**：不给答案，留下一个真问题——"苏轼从此还敢写吗？敢。那这场案子到底改变了什么？"比任何结论都让人睡不着。

发散的纪律：**主体评论（钉死→翻转→落点）写完之后，才有资格发散**；发散只占一两句，且必须仍然从本期事实出发（对照的案例可以外延，论点不能外延）。发散是烟花，承重的还是框架。

**规则：一期只站 1–2 个尺度。** 通常从内层尺度立论（观众刚看完一个人的遭遇，情感账户在这里），用外层尺度收尾（"从个人的遭遇，落到历史的长河"）。五个全碰是综述，不是立场。

### 三个动作（点评的骨架，按序执行）

**动作一：钉死与飘着（立信）**
先划证据边界——哪些钉死，哪些飘着。不是免责声明，是**建立说话人的可信度**："今天讲这段历史，得先说清楚哪些是钉死的，哪些是飘着的。" 三句话内完成，飘着的点名讲法不一。

**动作二：翻转（给认知增量）**
给一个"原来该这么看"的再定位。三种可靠翻转：
- **重新定性**："贬谪黄州"实为"可控性处置"——换掉标签，露出机制
- **反鸡汤**："没有成就，只是逼出"——拒绝舒服的结论，功劳还给当事人
- **再归因**："每一环都没有人越轨"——把恶从个人挪到程序/结构
翻转必须能被已叙述的事件链**直接支撑**（二十余人名单=慑其群的实证）。

**动作三：落在人与物（收口）**
不落在抽象概念。落在人（牢里那个人和东坡上那个人放在一起，才算完整）、落在物（东坡的荒地、雪堂、赤壁的船——精神秩序要有物理地址）、或落在一个从事实里长出来的判断句收束。

## 结尾判断句的检验标准

1. **删掉故事它就不成立** — 判断必须依赖你讲的事实，不能是通用格言
2. **说出来观众会停一拍** — 有认知摩擦，不是复述共识
3. **只此一句** — 全点评最多一个金句，多了互相稀释
4. **当代词可入，学术黑话不可入** — "帅哥"可以（易中天），"高影响力异见者"要翻译成"杀一个苏轼，天下人会为他喊冤；废一个苏轼，天下人只会替他惋惜——惋惜，是安全的"

## Prompt template（写点评时的自检提示词）

```
写这段点评前，回答：

1. 我站哪 1–2 个尺度？（个人/国家/时代/文化/历史走向）内层是哪个，外层是哪个？
2. 我的翻转是什么？重新定性、反鸡汤、还是再归因？
3. 这个翻转能被故事里的哪个具体事实直接支撑？（写不出来=翻转是悬浮的，换）
4. 开场第一句落在什么具体物上？（诗句/人/物件。出现"回头看/综上所述/纵观"=重写）
5. 收尾落在人还是物？判断句是哪句？删掉故事它还成立吗？
6. 全段只有一句金句吗？
7. 念一遍：哪句是写出来的，哪句是说出来的？（写的删，说的留）
```

## Anti-patterns（一票否决）

- 开场"回头来看/综上所述/纵观历史" — 总结腔，观众开始离场
- 五个尺度全碰 — 综述不是立场
- 金句不依赖已讲事实 — 悬浮鸡汤
- 点评回放事件链 — 复述浪费观众时间（reviewer 会拦）
- "第一层/第二层/第三层"分层框架 — 材料腔复发
- 连续排比收尾 — 气势替代了内容
